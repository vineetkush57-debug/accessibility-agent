# Future Scope & Roadmap (Post-MVP)

The following capabilities are deliberately out of scope for the 8-hour hackathon MVP and tracked here for future development:

1. **Multi-Page Site Crawling & Aggregation**:
   - Depth-limited site crawler with aggregate site accessibility dashboards and trend graphs over time.
2. **GitHub Pull Request & VCS Integration**:
   - Native GitHub / GitLab bot that opens PRs proposing accessibility patches directly against template / source repositories.
3. **Framework Source-File Patching (AST Source Maps)**:
   - Mapping rendered HTML element patches back to React (JSX/TSX), Vue, Svelte, or Django templates using source maps and AST transformers.
4. **Interactive Keyboard & Focus-Order Testing**:
   - Automated tab-navigation tracing, focus-trap detection, and visible focus indicator verification via Playwright synthetic keyboard events.
5. **Authentication & Session-Protected Page Auditing**:
   - Form-based login recording, cookie / bearer token injection, and staging environment scanning.
6. **IDE & CI/CD Tooling**:
   - VS Code extension for live in-editor semantic a11y auditing.
   - GitHub Actions / CI plugin that fails builds if accessibility regressions occur.
7. **Organization Dashboard & User Accounts**:
   - Multi-tenant team management, compliance tracking, and automated recurring scan schedules.
